WHY AETHER

Small footprint. Big possibilities.

Everything you need is built in — and everything you don't need can be switched off.

🍃

Low-RAM by design

Background networking, translation, media routing and optimization hints are disabled by default. Your laptop stays cool.

🛡

Built-in blocker

Lightweight declarative rules stop ads and trackers before pages load — without rewriting the web.

▤

Vertical tabs

A slim side panel keeps dozens of tabs readable. One shortcut to show or hide it.

✦

Modern start page

Live clock, animated wallpapers, editable quick links, scratchpad and a focus timer — all stored locally.

🛍

Aether Store

Install and manage first-party extensions from inside the browser. No account, no remote updates.

⌘

Keyboard-first

Alt+Shift shortcuts for new tabs, settings, home, store, spotlight and blocking.

GET STARTED

Three steps, about a minute.

  1. Download the file for your platform.
  2. Linux: make the AppImage executable — right-click → Properties → Permissions → “Allow executing”, or run chmod +x Aether-x86_64.AppImage. Windows: unzip the portable build or run the installer EXE.
  3. Launch Aether. Linux: double-click the AppImage (or run aether). Windows portable: double-click Aether.vbs. Windows installed: use the desktop shortcut.

Linux needs FUSE; if AppImages won't start, run with APPIMAGE_EXTRACT_AND_RUN=1. Windows builds need Windows 10/11 x86_64 and no administrator rights for the installer.
